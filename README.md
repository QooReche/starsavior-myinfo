# 스타세이비어 내 정보 추출 도구

스타세이비어(Steam PC판)의 **내 보유 구원자 정보**를 [파티 편성 네비게이터](https://qooreche.github.io/starsavior-party-navigator/)로 한 번에 가져오는 도구입니다. (비공식 팬 도구)

## 사용법

필요한 것: Windows 10(1809 이상) 또는 11. 설치할 프로그램은 없습니다.

**1. 실행** — 시작 메뉴에서 **PowerShell** 을 열고(관리자 권한 불필요) 아래 한 줄을 붙여넣어 엔터를 누릅니다. 관리자 확인 창이 나오면 **[예]** 를 누릅니다.

```powershell
$f="$env:TEMP\ss_myinfo.ps1"; iwr -UseBasicParsing https://raw.githubusercontent.com/QooReche/starsavior-myinfo/main/myinfo.ps1 -OutFile $f; powershell -NoProfile -ExecutionPolicy Bypass -File $f
```

**2. 게임 로그인** — 새 창의 안내가 나오면 스타세이비어를 실행해 로그인합니다. 게임이 이미 켜져 있었다면 완전히 종료한 뒤 다시 켜세요.

**3. 엔터** — 로비가 뜨면 도구 창으로 돌아와 엔터를 누릅니다. 잠시 뒤 파티 네비게이터가 열리고 내 구원자가 자동으로 채워집니다.

바탕화면에 `내정보.json` 도 저장됩니다. 사이트가 자동으로 열리지 않으면 사이트의 **[내 구원자 → 내 정보 불러오기]** 에서 이 파일을 선택하세요.

## 안전한가요?

- 게임 파일을 고치지 않고, 게임 메모리도 읽지 않으며, 아무것도 설치하지 않습니다.
- 게임이 로그인할 때 받는 내 계정 정보를 Windows 기본 도구(`pktmon`)로 **지켜보기만** 합니다. 통신을 바꾸거나 끼어들지 않습니다.
- 읽는 작업은 **내 PC 안에서만** 이뤄집니다. 결과(`내정보.json`)에는 닉네임·UID·로그인 정보가 없고, 구원자 육성 수치(별·공명·스킬·호감도·장비 등)만 있습니다.
- 작업 중 생기는 임시 통신 기록에는 로그인 정보가 섞여 있어서, 끝나면 **자동으로 삭제**됩니다.
- 결과는 사이트 주소의 `#` 뒤(해시)로만 전달됩니다. 이 부분은 서버로 전송되지 않고 내 브라우저 안에서만 읽힙니다.
- 관리자 권한이 필요한 이유는 Windows 내장 `pktmon` 이 관리자 권한을 요구하기 때문입니다. 도구는 `myinfo.ps1` 한 파일이며 열어서 확인할 수 있습니다.

## 문제가 생기면

- **"내 정보를 찾지 못했습니다"** — 도구 창의 안내가 나온 *뒤에* 게임을 켜서 로비까지 들어갔는지 확인하고 다시 해 보세요. 게임이 업데이트되면 데이터 형식이 바뀌어 **관리자가 도구를 고치기 전까지 실패할 수 있습니다.** 갱신을 기다려 주세요.
- **실패하면** 바탕화면에 `내정보_진단.txt` 가 생기고 탐색기가 그 위치를 열어 줍니다. **이 파일을 관리자에게 보내 주세요.** 닉네임·계정 정보는 들어 있지 않습니다.
- **통신 기록 파일(`%TEMP%\ss_myinfo\cap.pcapng`)이 남은 경우**(읽기 실패 시에만 남습니다) 이 파일에는 **계정 정보가 들어 있으니 다른 사람에게 보내거나 올리지 마세요.** 직접 지워도 됩니다.
- 그 밖의 문제는 이슈로 알려 주세요.

## 안내

비공식 팬 도구이며 게임 운영사와 무관합니다. 게임 약관상 이런 방식이 허용되는지는 보장할 수 없으니 사용은 본인 책임입니다.
