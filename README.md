# starsavior-myinfo

스타세이비어(Steam PC판)의 **내 보유 구원자 정보**를 [파티 편성 네비게이터](https://qooreche.github.io/starsavior-party-navigator/)로 가져오는 도구입니다. (비공식 팬 프로젝트)

## 사용법 (설치 없음, 한 줄)

1. **PowerShell** 을 엽니다(시작 메뉴 → "PowerShell"). 관리자 권한으로 열 필요는 없습니다.
2. 아래 한 줄을 붙여넣고 엔터를 누릅니다.

```powershell
$f="$env:TEMP\ss_myinfo.ps1"; iwr -UseBasicParsing https://raw.githubusercontent.com/QooReche/starsavior-myinfo/main/myinfo.ps1 -OutFile $f; powershell -NoProfile -ExecutionPolicy Bypass -File $f
```

3. 관리자 확인 창이 뜨면 **[예]** 를 누릅니다.
4. 새 창의 안내를 따릅니다.
   1. **스타세이비어를 실행합니다.** (이미 켜져 있었다면 완전히 종료한 뒤 다시 실행)
   2. 로그인해서 **메인 화면(로비)** 이 뜨면, 도구 창으로 돌아와 **엔터** 를 누릅니다.
   3. 실패하면 바탕화면에 `내정보_진단.txt` 가 생깁니다. (닉네임·계정 정보는 들어 있지 않습니다.)
5. 잠시 뒤 파티 네비게이터가 열리면서 내 구원자가 자동으로 채워집니다. (바탕화면에 `내정보.json` 도 생깁니다. 사이트가 안 열리면 사이트의 「내 구원자 → 내 정보 불러오기 → 파일 선택」으로 이 파일을 고르세요.)

요구 사항: Windows 10(1809 이상) 또는 11. 별도 프로그램 설치는 필요 없습니다(Windows 기본 기능만 사용).

## 무엇을 하나요

- 게임이 로그인할 때 서버에서 받는 **내 계정의 구원자 정보**를, Windows 에 들어 있는 `pktmon` 으로 **읽기만** 합니다. 게임 파일·게임 프로세스·통신 내용을 바꾸지 않습니다.
- 결과 파일(`내정보.json`)에는 닉네임·UID·로그인 정보가 **들어 있지 않습니다**. 구원자 ID 와 별·공명·스킬 레벨·호감도·장비·전술 레벨 같은 육성 수치만 담습니다.
- 작업 중 만들어지는 캡처 파일에는 로그인 정보가 섞여 있어서, 끝나면 **자동으로 삭제** 합니다.
- 사이트는 이 정보를 **서버로 보내지 않고** 내 브라우저(localStorage)에만 저장합니다.
- 관리자 권한을 요청하는 이유는 `pktmon`(네트워크 읽기)이 관리자 권한을 요구하기 때문입니다. 소스는 `myinfo.ps1` 하나이고 열어서 확인할 수 있습니다.

## 주의

- **비공식** 도구이며 게임 운영사와 무관합니다. 게임 약관상 이런 방식이 허용되는지는 보장할 수 없으니 **사용은 본인 책임** 입니다.
- 게임이 업데이트되면 도구가 동작하지 않을 수 있습니다("해독 불일치" 메시지). 이 경우 도구 갱신을 기다려 주세요.
- 오류가 나면 창에 표시되는 문구를 이슈로 알려 주세요.
